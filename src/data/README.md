# Data sources

Both files here are static builds generated by `scripts/build-data.mjs` (run
via `npm run build:data`) and are checked in so the app works with zero setup.

- **`dict.json`** — Chinese→English definitions, grouped by simplified
  headword (up to 3 senses each), derived from **CC-CEDICT** via the
  [cedict-json](https://github.com/matt-tingen/cedict-json) npm package.
  CC-CEDICT is released under
  [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) by
  [MDBG](https://www.mdbg.net/chinese/dictionary?page=cc-cedict).
- **`hskWords.json`** — word → HSK level (1–6), the lowest level at which
  each word is introduced. Derived from
  [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary)
  (MIT licensed).

To refresh either file, re-run `npm run build:data` (see the script for the
upstream URLs it expects locally) and commit the regenerated JSON.
